Perícia Digital para Advogados

Conhecimento técnico sobre provas digitais, Computação Forense e cadeia de custódia.

Este repositório é uma iniciativa da OliveiraPerito para compartilhar materiais técnicos e educativos destinados a advogados, defensores, assistentes técnicos e profissionais do Direito.

Nosso objetivo é facilitar a compreensão dos aspectos técnicos relacionados à produção, preservação, análise e contestação de evidências digitais.
